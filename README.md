## Overview
This project is a transaction intelligence system designed to simulate real-world fintech analytics. It focuses on understanding revenue performance, payment failures, and customer behavior using SQL and Python.

## Objectives
- Identify revenue leakage from failed transactions  
- Detect risky or abnormal user behavior  
- Analyze payment success rates across channels  
- Provide actionable insights for business optimization  

## Dataset
- 20,000 transactions  
- 2,000 customers  
- Multi-country (Nigeria, Ghana, Kenya)  
- Payment channels: Card, Transfer, USSD
  
## Tech Stack
- SQL (PostgreSQL-style queries)
- Python (Pandas, Matplotlib)
- Data Modeling & Analytics

## Key Analyses

### Revenue Analytics
- Daily & monthly revenue trends  
- Revenue contribution by channel  
- Top customer LTV analysis  

### Failure & Leakage Analysis
- Failure rate by channel  
- Revenue loss estimation  
- Retry behavior tracking   

### Customer Insights
- Customer segmentation  
- Retention & repeat behavior  
- Cohort-based revenue analysis
